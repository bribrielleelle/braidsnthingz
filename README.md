# AURA Atelier Salon — Luxury Hair Salon & Booking Website

A modern, responsive, and elegant hair salon booking web application inspired by high-end boutique salon design aesthetics. Built with clean typography, soft warm neutrals (blush pink, cream, espresso, and muted gold accents), and a complete multi-step appointment reservation system.

## ✨ Features

- **Hero & Aesthetic Identity**: Arched editorial visual layout, bold typography (`Playfair Display` serif paired with `Plus Jakarta Sans`), trust badges, and quick reservation triggers.
- **Bespoke Services Menu**: Filterable catalog of treatments (Cuts, French Balayage, Lived-In Color, Japanese Scalp Head Spa, K18 Molecular Therapy, Bridal) with pricing, duration, and direct service reservation.
- **Resident Stylist Showcase**: Profiles with certified specialties, experience levels, ratings, and one-click booking with that specific master artist.
- **Interactive Multi-Step Booking Wizard**:
  - Step 1: Service selection with category filtering and price breakdown
  - Step 2: Stylist selection (individual master stylists or First Available)
  - Step 3: Interactive date picker (14-day window) & morning/afternoon/evening time slots
  - Step 4: Client information with contact details, notes, and hair history
  - Live preview summary card calculating subtotal and estimated duration
- **Interactive Before & After Slider**: Draggable slider to compare hair transformations in real-time.
- **Visual Portfolio & Lightbox**: Categorized gallery showcasing balayage, precision cuts, bridal updos, and salon atelier interior with high-resolution lightbox preview.
- **Client Reviews & Ratings**: 5-star verified testimonial cards with ratings and review metrics.
- **Floating "Book Now" Button**: Sticky mobile-first CTA button that follows the guest as they scroll.
- **Celebratory Booking Confirmation Modal**: Generates a unique appointment code (`#AUR-XXXX`), provides instant Google Calendar sync links, and triggers celebration confetti.
- **Hospitality & Contact**: Studio hours, address, phone, email, directions, FAQ accordion, and Instagram grid preview.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone or download repository
cd aura-salon

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` to view the application.

### Production Build
```bash
npm run build
npm run preview
```
